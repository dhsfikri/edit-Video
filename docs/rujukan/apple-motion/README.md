## Apa yang membuatnya "Apple / premium"
| # | Elemen | Butiran |
|---|---|---|
| 1 | **Latar cerah** | Putih / kelabu sangat cerah (#F2F2F2–#E6E6E6), kadang-kadang biru pucat. Sesekali tukar ke hitam penuh untuk kontras. Tiada gradient berwarna-warni. |
| 2 | **Komponen UI morph** | Satu bentuk **bertukar** jadi bentuk lain (bukan potong): titik → pil carian → kad produk (gambar + "Pay") → butang biru "Track Order" → titik. Saiz, sudut bulat dan isi beranimasi bersama. |
| 3 | **Gambar sebenar dalam kad** | Produk sebenar (contoh iPhone oren) dalam kad putih bersudut bulat dengan bayang lembut. Bukan ikon lukisan. |
| 4 | **Tipografi** | Sans-serif bersih, campuran berat (nipis + tebal dalam satu ayat: "Is it **possible to learn**"). Perkataan muncul satu-satu dengan blur. Huruf boleh morph ("MORPHING"). Kata kunci berwarna (oren / biru) atau bergaris bawah. |
| 5 | **Pil chat** | Gelembung chat iMessage hijau & biru, muncul bertindih. |
| 6 | **Widget iOS** | Kapsul hitam (pemasa, "Yes", "Well"), skrin telefon gelap dengan teks ditaip. |
| 7 | **Kursor** | Kursor tangan/klik menekan butang → mencetus morph seterusnya. |
| 8 | **Gerakan** | 60fps licin, ease-in-out lembut (tiada lantunan kartun). Sedikit condong 3D semasa kad bergerak. |
| 9 | **Emoji** | Sangat jarang & kecil (3 emoji dalam pil). Untuk video Sir: **TIADA emoji** (keputusan Sir 2026-11-16). |

## Terjemahan untuk video Sir (talking head)
- Video Sir = salah satu "komponen": kad bersudut bulat di atas latar cerah, boleh mengecil/membesar/morph.
- Pil carian/soalan untuk hook ("Nak orang percaya?").
- Kad produk dengan **gambar sebenar** dari pustaka (`aset/gambar/`), butang hitam/hijau ("Beli").
- Pil chat hijau (warna brand #25D366) & biru untuk dialog customer–seller.
- Morph antara komponen ikut ayat Sir; kursor klik untuk "tindakan".
