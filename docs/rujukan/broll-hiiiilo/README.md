## Prinsip yang kita ambil untuk B-roll Sir
1. **B-roll = komponen UI chat** dibina langkah demi langkah (bukan stok video): senarai inbox, kad chat, typing, balasan, pil status ("✓ Real buyer", "✓ Booked"), notifikasi, kalendar.
2. **Tajuk bernombor** `01 / 02 / 03` + satu perkataan tebal + titik ("Qualify.") + subteks kelabu kecil — struktur jelas.
3. **Satu warna aksen** untuk mesej "kita/seller" (rujukan: ungu; Sir: **hijau #25D366**). Customer = kelabu/putih.
4. **Nombor mengira** untuk kesan skala ("80 orang").
5. **Silih ganti latar gelap ↔ cerah** antara babak; transition = potong keras / **sapuan pepenjuru**.
6. Rentak laju: setiap elemen masuk 0.2–0.4s, babak 2.5–3s.
7. Semua generik (nama rekaan, tiada logo WhatsApp sebenar) — selari peraturan BRANDKIT.
