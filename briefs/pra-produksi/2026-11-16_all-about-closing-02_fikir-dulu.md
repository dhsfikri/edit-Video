## 0. Reference (viral-reverse-engineering) — PERLU INPUT SIR

Saya **tak boleh tonton video TikTok dari link** (platform tertutup). Jadi saya tak reka analisis video yang saya tak nampak.
Untuk bedah video viral, Sir hantar **3–5 video** niche sales/closing yang Sir rasa menjadi. Untuk setiap satu:

| Perlu | Contoh |
|---|---|
| Link + screenshot frame pertama (0–3s) | |
| Ayat hook pertama (apa dia cakap) | |
| Apa berlaku (ringkas) / transcript | |
| Views, like, share, save, komen | |
| Anggaran follower creator | |
| 3–5 komen paling atas | |

Atau: install plugin **Manifold** → saya boleh tarik data TikTok sendiri (`analyze-viral-tiktok`, `find-tiktok-hooks`).

**Sementara tu**, konsep di bawah guna mekanisme yang memang terbukti untuk video talking-head pendek (bukan tiru mana-mana video):
- **Kenal diri sendiri** → penonton nampak *dirinya* dalam kesilapan tu ("eh, aku buat ni") → itu pencetus share/save.
- **Gelung terbuka (open loop)** → tunjuk akibat dulu, jawapan kemudian → orang tunggu sampai habis.
- **Nilai praktikal** → satu ayat yang boleh terus copy-paste → pencetus **save**.

## 2. Tiga konsep (Sir pilih satu)

| | Konsep | Kekuatan | Kelemahan |
|---|---|---|---|
| **A ⭐ (cadangan)** | **"Rewind"** — tunjuk seller balas "Ok takpe" → 3 hari *seen* → Sir petik jari, *rewind* → balas guna ayat betul | Ada cerita: konflik, akibat, twist. Visual berubah setiap 2–4s | Perlu rakam 4 setup |

## 3. C — Skrip AV dua lajur (Konsep A)

| # | Masa | AUDIO (didengar) | VISUAL (dilihat) |
|---|---|---|---|
| 1 | 0–3s | [Dialog] "Customer cakap *'nanti saya fikir dulu'*… dan awak balas *'okay'*?" | **CU muka Sir**, pegang phone, angkat kening. Tajuk: *customer cakap* / **NANTI SAYA FIKIR DULU?** [SFX] signature |
| 2 | 3–6s | [Dialog] "Ni yang selalu jadi." | **Insert OTS**: tangan taip di phone → mockup chat: C: "Nanti saya fikir dulu ya" · S: "Ok takpe, roger ya 👍" [SFX] hantar |
| 3 | 6–10s | [VO] "Sehari. Dua hari. Tiga hari. *Seen.*" | **Mockup chat**: cap masa melompat Isnin→Rabu, ✓✓ "Seen", tiada balasan. Potong ke **CU Sir** tengok phone, muka kecewa (lakonan). Teks: **3 HARI. SEEN.** [SFX] tik-tok jam |
| 4 | 10–12s | [Dialog] "Okay. *Rewind.*" | **MS Sir** petik jari ke kamera → kesan *rewind* (VHS / rewind laju) [SFX] rewind |
| 5 | 12–19s | [Dialog] "Balas macam ni: *'Boleh, takde masalah. Boleh saya tahu, bahagian mana yang Cik nak fikirkan — harga, atau sesuai ke tak dengan Cik?'*" | **MS Sir** depan kamera, nada tenang. Ayat muncul sebagai **kad ayat** (boleh screenshot) — keyword **BAHAGIAN MANA?** |
| 6 | 19–24s | [VO] "Tengok apa jadi." | **Mockup chat** (label kecil *contoh*): C: "Sebenarnya harga tu agak tinggi sikit…" → S: jawab ringkas → C: "Ok boleh, hantar link" ✅ |
| 7 | 24–28s | [Dialog] "Sebab *'fikir dulu'* tu bukan jawapan. Itu tanda ada soalan yang dia segan nak tanya." | **CU Sir**, jari tunjuk ke kepala. Teks: *bukan jawapan* → **SOALAN TERSEMBUNYI** |
| 8 | 28–31s | [Dialog] "Save video ni. Lain kali dia cakap *'nanti saya fikir dulu'*…" | **MS Sir**, angkat phone balik (sama macam shot 1 → **loop**). CTA: 🔔 save & follow @sirdharma_ |

**Peraturan dipatuhi:** visual tak pernah "Sir bercakap" dua kali berturut-turut tanpa perubahan (CU → insert → chat → MS → kad → chat → CU → MS).

**Hook alternatif (rakam semua, pilih masa edit):**
- B: "Kalau customer cakap *'nanti saya fikir dulu'*, jangan balas *okay*."
- C: "Ayat *'nanti saya fikir dulu'* ni dah bunuh banyak sale awak."

## 6. E — Semakan atas kertas (timing pass)

- Kiraan perkataan dicakap: ±72 patah → pada ~140 patah/minit ≈ **31s** termasuk jeda. ✅ dalam sasaran.
- Kalau terlebih: buang shot 6 (hasil chat) dan biar ayat closing terus ke shot 7.
- **Semakan kejujuran:**
  - Skit **jelas lakonan** (Sir main dua watak, tiada pelakon menyamar customer sebenar).
  - Chat hasil berlabel *contoh*, tiada screenshot palsu.
  - Tiada janji "confirm closing". Ayat ni **buka perbualan**, bukan jamin jual.
