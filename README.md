# Edit Video — Flow TikTok 30 Saat

Repo ni simpan SOP / flow untuk edit video TikTok jenis **talking head + B-roll + hook title motion graphic + subtitle**, durasi **30 saat**.

| Fail | Guna untuk apa |
|---|---|
| [`FLOW-EDIT-VIDEO.md`](FLOW-EDIT-VIDEO.md) | Flow penuh step-by-step, dari skrip sampai upload |
| [`templates/brief-edit.md`](templates/brief-edit.md) | **Wajib** — plan & brief sebelum edit, tunggu approval |
| [`templates/skrip-30s.md`](templates/skrip-30s.md) | Template skrip + shot list (copy setiap kali nak buat video baru) |
| [`templates/checklist-qc.md`](templates/checklist-qc.md) | Checklist QC sebelum export & upload |

> ⚠️ Peraturan: setiap video mesti **plan & brief dulu**, dan edit hanya selepas approval. Lihat [`CLAUDE.md`](CLAUDE.md).
